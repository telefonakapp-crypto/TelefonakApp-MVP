# Admin Web

Staff dashboard for Telefonak (Vite + React + TypeScript).

Setup and architecture: [root README](../README.md) and [docs/05_ADMIN_PANEL.md](../docs/05_ADMIN_PANEL.md).

```bash
cp .env.example .env
npm install
npm run dev
```

Requires the API on port 3000 and a Super Admin (`cd backend && npm run create-super-admin`).
