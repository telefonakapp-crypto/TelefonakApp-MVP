# Phone catalog sources

Manufacturer-verified and GSMArena-cross-checked phone models for Telefonak.

Smartwatch catalog data is unchanged. Existing listing rows are not deleted.
Unofficial storage associations are deactivated, not removed.

Research date: 2026-08-29.

## Naming

| Brand | Model name pattern |
| --- | --- |
| Apple | `iPhone 15 Pro Max` (no Apple prefix). Original handset is `iPhone (1st generation)`. SE generations keep existing names: `iPhone SE`, `iPhone SE (2020)`, `iPhone SE (2022)`. |
| Samsung | `Galaxy S24 Ultra` (no Samsung prefix). Foldables keep the existing spaced form `Galaxy Z Fold 5`. |
| Google | `Pixel 8 Pro` |
| Redmi / POCO | Own brands (moved off Xiaomi). Model names keep the Redmi/POCO prefix. |
| Other Android | Existing names kept (`Huawei P60 Pro`, `Oppo Find X7 Ultra`, `Honor Magic 6 Pro`). |

## Storage policy

- Only capacities sold as official internal SKUs are attached.
- microSD / Nano Memory expansion is not a catalog storage option.
- Regional SKU unions are documented on the model notes below when Google/Apple pages disagree by market.
- 2 TB is stored as `2048` GB with label `2 TB`.
